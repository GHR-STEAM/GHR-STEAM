## Required audit fields

For each repository, the next audit pass must capture:

- Last meaningful commit date and recent commit frequency.
- Owner/maintainer and repository permissions.
- Fork status, upstream URL, and divergence from upstream.
- Branches, tags, releases, and default branch health.
- README quality, license, contribution guidance, and project purpose.
- Source layout, tests, CI, dependency automation, and security alerts.
- Open issues, pull requests, discussions, and release cadence.
- Secret-scanning and dependency-alert status, where available.
- Duplicate candidates supported by file/content/history evidence.
- Recommended lifecycle: active, paused, archived-candidate, or needs-triage.

## Important interpretation

A small repository is not automatically disposable. A large repository is not automatically active. A repository with a generic name is not automatically a duplicate. No lifecycle decision is made from the current snapshot alone.
